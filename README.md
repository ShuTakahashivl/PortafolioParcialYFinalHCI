# Aplicación Móvil de Organización Personal

Portafolio del proyecto de **Human-Computer Interaction** (FIUNI, 2026): el proceso de diseño centrado en el usuario de una app móvil que ayuda a estudiantes universitarios sobrecargados a organizar y priorizar sus tareas sin depender de su memoria.

## Organización del repositorio

`index.html` es el portafolio, `css/` tiene los estilos, `img/` las capturas, fotos y diagramas, y `anexos/` los documentos de trabajo de cada etapa (investigación, definición, ideación y evaluaciones) como evidencia.
